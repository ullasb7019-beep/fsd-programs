2) explain Types of dependency injection?
Answer. 1) Constructor injection: When we inject two dependency of one class into another class via Constructors then called as constructor injection.
2. Setter injection: When we inject the dependency Of one class Into another class via Setter then Called a sector injection.
3. Field injection: Dependencies are directly injected Into the field by Using @Autowired Or manually. This is nothing but field injection it is very complex to develop. So for it is not recommended for testing.
